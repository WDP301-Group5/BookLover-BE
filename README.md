# BookLover-BE

Dự án dùng nodejs + expressjs + typescript + mongodb

## Environment Variables

### AI Content Moderation

| Variable | Description | Required |
|----------|-------------|----------|
| `AI_MODERATION_ENABLED` | Enable AI moderation (true/false) | No (default: false) |
| `GEMINI_API_KEY` | Google Gemini API key | Required if AI moderation enabled |

### Getting API Keys

1. **Gemini API**: https://aistudio.google.com/app/apikey
